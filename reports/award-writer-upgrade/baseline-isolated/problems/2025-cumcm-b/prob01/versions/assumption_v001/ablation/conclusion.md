## 解读（ablation 结论）

1. **干涉叠加项是厚度信息的唯一载体（A1）**：移除 (3.5) 的 cosδ 干涉项后模型不含 t，
   rmse(t) 剖面完全平坦（flatness=0），厚度不可辨识。这定量确认了 A11（相干性）假设的
   必要贡献：两光束干涉模型 (3.5) 的干涉项不是可选项，而是反演厚度的必要条件。
2. **衬底界面反射项是干涉条纹的必要条件（A2）**：R2→0 后（1-R1)²R2 项与干涉幅度 √(R1R2)
   同时消失，模型退化为界面 1 直接反射（不含 t），厚度同样不可辨识。定量确认 A6
   （衬底-外延层折射率差是条纹前提）的物理作用：prob02 若实测条纹对比度极弱，
   应核查衬底折射率取值或结构假设。
3. **偏振平均是安全简化（A3）**：s/p/avg 三种偏振模型反演同一 avg 观测谱，厚度最大相对差
   0.012%（阈值 1%），远小于方法层噪声水平。定量确认 A4（相位跃变不改变同型极值间隔、
   相位 δ 与偏振无关）：prob02 无需逐偏振反演，avg 模型足够。
4. **多初值模块必要，单初值退化可复现（A4）**：仅方法 A 解析初值（θ=10°: t0=10.44 → t=10.60；
   θ=15°: t0=10.47 → t=10.60）落入 cosδ 周期歧义局部极小，相对真值偏差 5.99%/6.03%
   （>2%）；多初值（网格扫描 + ±period 布点）精确恢复 t=10.000（误差 ~0）。与
   implementation §6.1 预警（t0=10.44 → 10.63）及 formula_validation §6 周期歧义分析
   方向量级完全一致。prob02 实测反演必须沿用多初值策略（与 robustness 阶段的网格扫描
   初值升级结论一致）。
