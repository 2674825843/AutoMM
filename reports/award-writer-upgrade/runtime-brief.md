## Design decisions
1. New versions opt in with immutable writer_manifest quality contract (schema/version and frozen rules hash). Freeze rule pack from config/paper.yaml writing_rules path (templates/paper/award-writing-rules-v1.json; parent will supply {version:'award-writing-v1',rules:[{id,principle,applies_to:[...],cautions,sources:[{path,sha256,pages:[int]}]}]}). Strict validation for configured new rule pack; legacy versions without contract keep legacy route, but deleting expected contract must NOT silently downgrade active quality paper. Bind expected quality contract in durable paper state as well as manifest. Snapshot policy max revisions at prepare, preserve across revisions.
2. Durable writing_plan.json captures evidence_hash, per-question answers/claims (with exact paragraph anchors/excerpts and evidence IDs), required semantic roles (abstract, problem, analysis, assumptions, symbols, data, model+solution+results+reliability per question, limitations, conclusions, references and reproduction when applicable), selected and omitted figures/citations with reasons, warning disclosures. Use document section/paragraph IDs with Pandoc attrs or source-only comments (must be removed from final). User permits adaptive heading names, not missing content. Select used figures/citations only; audit every omitted item. Preserve every scientifically relevant warning/counterexample even if its figure omitted. Initial scaffold should be honest/incomplete planning material, not fabricated polished claims or arbitrary truncation of formulas. No literal all-artifacts dump, no quality-log prose in generated public text. Writer fills plan and paper in separate checkpointed invocations (planning then drafting) if needed. Evidence references alone don't establish truth: semantic reviewer must inspect actual referenced artifacts.
3. Independent paper-reviewer role in registry and prompt, read-only draft/plan/evidence/ frozen rules. Can only submit structured review through controlled schema command, not arbitrary transition/research writes. Review findings each severity blocking/advisory, location real excerpt/anchor, evidence-based reason, specific revision instruction. Require explicit per-question/claim/warning coverage assessments even empty findings; reject marker-only empty semantic content. Persist review bound to exact draft, plan, evidence, rules hashes. Use existing response/transaction mechanism (add narrowly authorized record_paper_review command) and staged workflow actions, not untracked state edits. Read-only execution restriction should be enforced as far as existing transport allows; don't merely rely on prompt. Detect unexpected artifact mutation and strictly fail.
4. Validation distinguishes mandatory deterministic/evidence constraints and semantic findings. Advisory findings lead at most 3 revisions after initial draft, then allowed PASS with warnings; blocking failures at cap park paper for attention without scheduling repeated agents/versions or publishing. No human-blocked misclassification solely for stylistic issue. Persist counters across new versions, max3 exact; retry same transport attempt doesn't spend content revisions. Existing runtime transport retry policies bounded, ensure exhausted reviewer errors don't spin forever. Checkpoints hash bound and resumable after interrupt; don't create duplicate revisions on repeated action. Content revisions keep history. Never reset accepted science gates.
5. New contract check in render_paper / verify_rendered_version / publish and cache reuse: required review matches current draft/plan/rule/evidence before rendering and before publishing; stale/missing review fail. Audit reports and source hashes included in version/delivery internal publication manifest. Legacy v007 not edited or rerendered.
6. Update Writer prompt and template: problem-specific titles; abstract method/result/verification, selective result+unit bold; formulas purpose, symbols units, derivation only accepted; each result observation-evidence-explanation-boundary; conclusions respond per question; no copied award facts. No all-figure/all-reference obligation for quality contract. Rules pack provenance never promoted into research citations. All copied support pictures remain selected publication figures with same public numbers.
