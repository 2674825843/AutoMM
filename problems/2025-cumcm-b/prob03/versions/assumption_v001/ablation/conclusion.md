## 解读（ablation 结论）

1. **色散项非 t̂ 点估计的关键复杂度（A1）**：N-SE → N-const（常数 n=n(5µm)）仅使 t̂ 移动 Δt=0.446% ≤ 2%。
   硅色散弱（Δn/n≈0.51%，robustness R2 的 Δt_disp≈0.503% 交叉一致）；色散项主要进入 δ(t) 相位频率与 g(ν) 周期，
   但主反演带的硅 Sellmeier 变化不足以显著改变条纹周期。色散项是物理忠实度项（非 t̂ 决定性项），保留为安全简化。
2. **多光束（Airy）高阶项不改变 t̂（A2，Q1 定量证据）**：两光束一阶 VP 基础上加 Airy 高阶谐波（cos2δ/sin2δ、cos3δ/sin3δ）
   后 t̂ 移动 Δt=0.300% ≤ 1%（更严阈值）。这直接定量验证 **L17「无吸收时 Airy 极值位置不变性」**：
   多光束的高阶反射仅改变干涉幅值/背景，不改变相位频率 → 不改变 t。与 robustness R5（η_mb≈0.111%≪τ_mb=10%）
   互补：R5 从残差改善率侧、A2 从「是否改变 t̂」侧共同确认**硅片两光束适用、无需 Airy 修正**。
   因此题面 Q1 的定量答案是：多光束对厚度计算精度的影响 ≈0（Δt≤0.3%），可忽略。
3. **基线多项式项是拟合优度的必要组件（A3）**：p=3 → p=0 后 t̂ 仅移动 Δt=0.574% ≤ 2%（未改变相位频率机制），
   但加权 RMSE 由 2.707e-3 升至 2.965e-3（+9.5%）。基线多项式 B(ν) 吸收 DC 基线/慢变趋势，不进入 δ(t) 相位频率，
   因而是**拟合优度必要、t̂ 非决定性**的组件；保留低阶基线（p=3）是平衡偏置-方差的合理选择。
4. **两角共享 t 约束是安全一致性约束（A4）**：shared=True → False 后每角独立 t̂=3.4507/3.4463 µm，
   与共享 t̂=3.4477 µm 最大偏差仅 0.089% ≤ 2%，且 ε₁₂=0.130% ≤ 2%。共享约束未强加偏差，反而通过公共相位频率
   增强 t 的统计稳定性（两角同时满足同一物理厚度），为安全、可保留的一致性约束（与 robustness R1 嵌套 F 检验接受共享 t 一致）。

## 结论分级与边界（如实记录）

- 全部判据与预期一致 → **`components_confirmed`**：色散项/基线多项式项/两角共享 t 约束为**安全简化**，
  多光束（Airy）高阶对 t̂ **无贡献**（L17 定量成立）。
- **边界的定性说明**（非不稳定，仅量级提示）：
  - `A1` 唯一性比值 1.018（弱色散下周期邻近候选接近简并）——与 robustness R8 报告项一致，全局唯一性由 formulation §7.6
    预注册判据保障；
  - `A2` 加高阶谐波后 RMSE 略降（2.707e-3 → 2.572e-3，−5.0%）：多光束复杂度带来微小拟合增益，但**不改变 t̂**，
    符合「多光束可忽略但对残差有微弱改善」的物理预期；
  - `A3` p=0 时 RMSE 上升 +9.5%：表明基线项不可省略（否则慢变背景被误吸入干涉项，虽本例 t̂ 仍稳定）。
- **与 robustness 的边界分工**：robustness 回答 t̂ 对**输入/情景不确定性**（R1–R8）稳定（STABLE）；
  ablation 回答**模型内部公式项/算法模块/约束的必要性**（A1–A4）。二者共同支撑「模型复杂度与参数选择对结论稳健、
  答案由相位频率机制主导」。
