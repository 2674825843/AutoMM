## 3. 等价性验证（修订相关）

- **方法 A（常数 n）与色散相位法（B10）**：带内弱色散极限 g(ν_{m+2})−g(ν_m)≈ncosθ'Δν，故 t_phase→t_A。带内 ν∈[2000,4000]，n 从 2.4954→2.5839（约 3.5% 变化），常数 n 假设带来约 4% 系统偏差（与本版 §4.2 N-const 基线一致）；该偏差纳入 M3 基线报告，不进入主交付。✓
- **P1 与 P2**：当 n_sub 取联合最优值时，P1 与 P2 的 t 应一致（§13.1 合成复核，P1/P2 在带内 t 偏差 <0.1%）。✓
- **谱段截断 vs 全谱**：全谱（含 ν<2000 色散缺口）在 v001 给出 Δt_disp=37.4%；截断后带内色散唯一（Sellmeier），Δt_disp→0。Δt_inv_band=(t_trunc−t_full)/t_trunc 量化该差异，作为截断合理性证据。✓

## 4. 守恒与能量检查

- 无吸收时单界面 R+T=1；两光束模型只保留一次往返项（B4/A1），R∈[0,1]（继承 v001 §4，数值例 R∈[0.15,0.25]）。✓
- 带内 R₁R₂≈(2.5−2.58)²/(2.5+2.58)²…：n_sub≈2.58、n≈2.56 → R₂≈(0.02/5.14)²≈1.5×10⁻⁵，干涉振幅 2(1−R₁)√(R₁R₂) 约为 √(0.19×1.5e-5)×2×0.81≈2.7×10⁻³（约 0.3% 反射率调制）。实测带内条纹对比度 3–17%，说明真实 n_sub−n 差异或噪声/色散使对比度高于纯 Fresnel 常数预测，本版以实测残差为准（§13）。✓
- 预处理不改能量语义：归一化只做 %→比例；异常点/reststrahlen/谱段截断在权重层面处理，不改原始数据。✓

## 5. 单调性与极值（继承）

- δ(ν) 在带内对 ν 单调递增（弱色散，ncosθ' 变化平缓）→ 极值有序、无级次交叉。✓
- Δν∝1/t；峰/谷交替（相邻差 π，同型差 2π）。✓
- 带内约 2.2 个同型周期，n=2001 点连续相位 → 相位频率信息足以确定 t（§13.1 加噪恢复验证）。✓

## 6. 数值可解性（修订相关）

- **(5.1) 反演**：连续参数 (t,n_sub)（或 t），正模型解析 O(N)，目标光滑；LM/信赖域收敛。t>0、n_sub>n 有界，唯一最优由多初值全局搜索保证。✓
- **n_sub 可辨识性（pivotal）**：带内 n_sub≈n（弱对比度），R₂ 小，n_sub 主要贡献于振幅/包络；t 由相位频率独立确定（§13.1 证明 t–n_sub 解耦，偏差<0.1%）。故 P2 联合反演在带内**同时约束 t 与 n_sub 可行**；若实际对比度过弱（实测 RMSE≈0.009 显示仍能可靠恢复），回退 P1+文献取值。✓
- **两角一致性 F 检验**：嵌套模型、单自由度差，标准 F 检验；样本量 N_tot≈8300，临界 F_{0.05}(1,8297)≈3.84；检验统计量有解析闭式，n_sub 为公共参数（不引入额外自由度）。✓
- **求解器选择**：连续、光滑、小规模，精确 NLS 充分；无需 MILP/启发式（formulation §5.3）。✓
- **谱段截断的可解性代价**：牺牲 ν∈[1000,2000] 强对比度区（约 33–38%），换取带内色散精确；带内 2.2 周期 + 连续相位足够恢复 t（§13.1）。✓
