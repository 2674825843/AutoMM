# prob02 公式验证（formulation_v003）

> 对应 `formulation.md`（formulation_v003），假设版本 assumption_v001。
> 验证范围：量纲、边界、极限、等价性、守恒、单调性、数值可解性与符号一致性。本版为 v002 修订：**把主反演从"全谱幅值 NLS"改为"基线-干涉分解 + 一维相位频率扫描（variable projection）"**，从而消除 v002 computation 暴露的 M1/M2/M3 两数量级冲突与四项判据超阈（根因见 formulation §0）。继承的正模型（(2.1)–(2.4)、Fresnel、相位、极值）沿用 v001/v002 已验证结论；本版对**新方法结构**做量纲/边界/等价/可解性复核，并用只读实测探针验证方法有效性（§13）。

## 3. 等价性验证

- **变量投影与物理两光束模型关系**：把 (2.3) 的 DC 项近似为多项式 B(ν)、干涉强度幅值 A(ν) 近似为 √(C²+S²)（多项式 C、S），则 (5.2) 是 (2.3) 的**半参数化**版本——仅把"缓慢变化的 DC 与包络"自由化，而不改变干涉**相位频率**与 t 的关系。当 p、q 足够且 A(ν)、D(ν) 平滑时，两者给出相同的 t（§13.4 交叉验证：从 t̂=7.4 启动的物理正模型 NLS 收敛到 ≈7.45，一致）。✓
- **A=√(C²+S²)**：A cos δ = A cosφ cosδ − A sinφ sinδ → C=A cosφ、S=−A sinφ（相位 φ 被吸收）。✓
- **t 与 n_sub 解耦**：由于 t 只通过 δ 的频率进入 (5.2)，而 C、S 可任意调整幅值，故 t 的估计**不依赖** n_sub/幅值；n_sub 仅在事后由 A=√(C²+S²) 反演（§7.3）。✓
- **方法 A（常数 n）与相位/频率法**：带内弱色散极限下 Δg≈n cosθ' Δν，故 t_phase→t_A；带内色散约 3.5%，常数 n 近似带来约 4% 系统偏差（B10 基线）。✓

## 4. 守恒与能量检查

- 无吸收时单界面 R+T=1；两光束模型只保留一次往返项（B4/A1），R∈[0,1]（继承 v001 §4，数值例 R∈[0.15,0.25]）。✓
- **带内弱对比度**（n_sub≈n≈2.58）：R₂≈(0.03/5.16)²≈3.2×10⁻⁵，干涉幅值 2(1−R₁)√(R₁R₂)≈2×0.81×√(0.19×3.2e-5)≈0.0040（约 0.4% 反射率调制）。与 §13.2 实测 A≈0.0040 一致。**这解释了两光束模型在带内"幅值信号弱、但相位频率信号强"的信息结构**，是本版方法的物理根据。✓
- 预处理不改能量语义：归一化只做 %→比例；异常点/reststrahlen/谱段截断在权重层面处理，不改原始数据。✓

## 5. 单调性与极值

- δ(ν) 在带内对 ν 单调递增（弱色散，ncosθ' 变化平缓）→ 干涉条纹有序、无级次交叉；g(ν) 单调递增。✓
- Δν∝1/t（Δg=1/(2×10⁻⁴t) 恒定），峰/谷交替（相邻差 π，同型差 2π）。✓
- J(t) 对 t 高度非凸（含 Δt_amb 周期折返），但色散（g 随 ν 变化）打破周期等价性 → 全局扫描可区分 t 与 t±k·Δt_amb（§13.1）。✓

## 6. 数值可解性

- **(5.5) 线性 LS**：对固定 t，设计矩阵 Φ(t) 列数 = (p+1)+2(q+1)（默认 p=3、q=1 → 8 列），远小于 N≈4148/角 → 超定、可解；用 QR/正规方程，条件数通过多项式归一化（中心化/施密特正交化，§13 探针用 QR）控制。✓
- **(5.6) 一维扫描**：t 在 [t_lo,t_hi] 上细网格（步长≤0.01 µm），每点一次线性 LS，O(K·N·d²)，K≈数百~1000 → 秒级/角。全局扫描不受局部极小困住（v002 全谱 NLS 的失败点）。✓
- **唯一性**：全局最小在真实 t≈7.4 处显著（RMSE 0.0013 vs 次小 0.0030），可辨识；用 §7.4 的"ΔJ 显著性判定 + 区间内唯一性"验证。✓
- **n_sub 弱可辨识**：由幅值 A≈0.004 反演 R₂≈3.2×10⁻⁵；A 的小幅噪声扰动会使 R₂（因而 n_sub）明显变化 → n_sub 弱可辨识（B7）。但因 t 与 n_sub 解耦，**n_sub 弱可辨识不影响 t**，故不构成可解性障碍。必要时回退文献取值。✓
- **两角一致性 F 检验**：嵌套模型（共享 t vs 独立 t），自由度差=1；样本量 N_tot≈8296，临界 F_{0.05}(1,·)≈3.84；本版实测 ε₁₂≈0.35% → 接受共享 t。✓
- **求解器选择**：一维扫描 + 线性 LS 属精确方法，充分；无需 MILP/启发式（formulation §5.6）。✓

> 与 v002 的差异：v002 的全谱 NLS 目标是**非线性幅值最小二乘**（同时拟合 t 与 n_sub），在弱对比度 + 未建模基线下面非凸且被基线主导 → 落入错误盆地（M1=0.305）。本版换为**一维相位频率扫描**（t 与基线/幅值解耦），目标平坦化、劣化到唯一全局极小。这是可解性层面的**结构性修复**，非参数微调。✓
