# prob02 ablation 适用性决定

> 阶段：ablation ｜ Agent：ablation-analyst ｜ 日期：2026-08-29
> 问题：2025-cumcm-b / prob02（碳化硅外延层厚度实测反演与可靠性分析，assumption_v001 / formulation_v003）

## 决定：适用（completed）

## 理由

1. **主方法（M1 = 基线-干涉分解 + 一维相位频率扫描，variable projection）存在可解释、可分离的
   公式项与算法模块**：formulation_v003 §5 把两光束反射率分解为 `R = B(ν) + C(ν)cosδ + S(ν)sinδ`，
   其中 B(ν) 为吸收慢变 DC 基线的低阶多项式、C/S(ν) 为吸收干涉包络与相位跃变的低阶多项式、
   δ(ν)=4π×10⁻⁴·t·g(ν) 的**频率/周期**承载厚度信息；色散 n(ν) 由 Sellmeier（N-SE，B6）给出；
   两角一致性用共享 t（M_shared）；t 与 n_sub 解耦。这些项/模块可以独立移除或替换而不改变题目定义，
   满足 knowledge/robustness-ablation.md §消融设计的适用条件。

2. **REQUEST.md 质量标准明确要求复杂算法必要性证据**：「复杂算法必须有必要性、对比实验和可解释性」。
   prob02 主方法 M1 是 formulation_v003 为修复 v002 模型可辨识性结构缺陷（主方法 M1 与 M2/M3 相差
   两个数量级、全谱 NLS 被未建模基线主导）而做的**方法论重构**，其三个结构性选择——基线-稳健分解、
   一维相位-频率 variable projection、t 与 n_sub 解耦——是否真正贡献厚度反演结果，需要 ablative 证据。
   robustness 阶段已覆盖**参数/输入/情景不确定性**（色散 ±0.5%、谱段截断、n_sub 幅度扰动、噪声 CI、
   异常点、多光束诊断、基线/包络阶数），但未检验**模型内部公式项与算法模块的必要性**，二者互补。

3. **存在已文档化的可检验机制**：formulation_v003 §0 明确 v002 根因一为「未建模的慢变基线主导目标」
   （全谱幅值 NLS 收敛到非物理小 t 盆地 t≈0.3µm）、根因二为「弱对比度下 t 为频率型、n_sub 为幅度型，
   二者不应在同一非线性目标里耦合」；B10 已文档化「常数 n 近似在 2000–4000 cm⁻¹ 引入约 4.2–4.7% 系统偏差」；
   computation/robustness 阶段已记录「物理正模型 NLS 交叉校验与主结果差约 5.5%」——这些机制断言可以用
   消融定量验证：移除基线分解/色散/相位-频率方法后结果应偏置或退化。

4. **真实实测数据 + 完整模型作为内部对照**：prob02 有附件 1/2 实测谱，完整模型（F0）给出 t̂(共享)=7.2158µm
   （computation v003，results/thickness_inversion_v003）。消融以完整模型为内部对照，每次只改变一个
   目标项，其余（数据、种子、谱段、预处理、扫描配置、多项式基）保持一致，正可直接对比组件贡献。

## 消融方向（3–4 个公式项/算法模块，与 robustness 不重复）

| 编号 | 消融对象 | 移除/替换操作 | 理论作用 | 预期方向 |
|---|---|---|---|---|
| F0 | 完整模型（对照） | 无 | M1：基线-干涉分解 + 一维相位-频率扫描（N-SE，p=3/q=1，两角共享 t，t 与 n_sub 解耦） | t̂≈7.216µm、J(t) 全局唯一、拟合低残差 |
| A1 | 色散 n(ν)（B6/M3） | N-SE（Sellmeier）替换为 N-const（常数 n=Sellmeier(5µm)） | 色散修正 g(ν)=n(ν)νcosθ'，相位频率依赖 n(ν)（B10） | 常数 n 引入约 4.2–4.7% 系统偏差 → t̂ 偏置，色散贡献 |
| A2 | 基线多项式 B(ν)（§5.1/§5.3） | p=3 多项式基线替换为 p=0（常数基线） | B(ν) 吸收带内慢变 DC 背景（v003 根因一修正） | 慢变背景未被吸收 → t̂ 偏置/残差上升，基线-稳健分解贡献 |
| A3 | 相位-频率 variable projection（§5.2/§5.5） | 替换为全谱幅值 NLS（v002 M1，invert_nls_multistart，初值由网格扫描） | t 由相位频率确定（强），非由幅值/绝对基线确定 | 幅值目标被基线主导 → t̂ 偏离（约 5.5%），相位-频率方法贡献 |
| A4 | 两角共享 t（M_shared，§5.6/§7.1） | 替换为每角独立 t（M_indep，shared=False） | 两角共享同一晶圆片同一厚度 t（B11） | 每角 t̂ 与共享 t̂ 接近、ε₁₂ 小 → 共享-t 为良性约束（安全，非失真） |

## 不适用部分（如实记录）

- **求解器/算法族对比（VP vs MILP/元启发式）**：formulation §5.6 已论证本问是 1 维连续非线性扫描 +
  每点线性 LS，正模型解析、目标对 t 高度非凸但有清晰全局极小，精确方法（一维枚举 + 线性 LS）充分，
  无需离散/元启发式；ablation 不重复算法族对比，仅消融方法内部模块（A3）。
- **多光束（Airy）模型展开**：formulation §7.6/B13 明确本问仅做两光束 vs Airy 诊断（改善 0.0%≤10%，
  两光束适用），完整推导与修正预留 prob03；本问不做 Airy 消融。
- **噪声/异常点/谱段截断的敏感性**：robustness 阶段已量化（C5 CI 半宽 0.091%、C7 异常点 0.0%、C3
  Δt_inv_band=58.4% 截断合理性证据），ablation 不重复，仅作组件必要性检验。
